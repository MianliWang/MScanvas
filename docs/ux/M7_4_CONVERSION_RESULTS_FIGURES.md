exact plan, inspect independent results, locate or explicitly adopt outputs,
recover owned temporary output, and export the intended scientific figure.

conversion, backend and scientific-export lanes. Active Clear captures exact
members and an operation incarnation. Stop waits outside locks required by the
worker; commit revalidates under drop delivery and workspace mutation gates.
All active queue members are protected, including waiting and finished rows.
Clearing rows never deletes sources or finalized outputs.

Finalized-output IDs resolve retained per-member tickets. Read-only destination
holds exclude rename/delete and directory writes before exact file admission.
File identity/digest and writer-excluding holds survive the platform handoff.
The fixed Windows adapter uses `ShellExecuteExW`; existing pinned feature
resolution already supplies its consumed APIs, so no dependency change was
needed. OS acceptance does not prove external rendering or later custody.

Staging authority is retained from atomic creation, not reconstructed from a
marker. Empty parent/root/output directories exclude in-place reparse writes.
Only after a pinned root keeps its parent nonempty does an identity-checked
parent hold permit child publication. Initial quiescent child identities are
frozen once; partial cleanup retains proof, excludes foreign entries/hard links,
and never enlarges deletion authority. Unconfirmed processes and lost proof
refuse cleanup. Explicit reclaim returns to a fresh plan without clearing
quarantine or changing the original conversion result.

Figure preview and saving use the same canonical specification and retained
scientific source. Pending viewer gestures do not commit ranges. Dialog kind
keeps spectrum/RT scope semantics stable even when invalid dimensions prevent
a request. Preview generations reject old answers and require explicit source
replacement acceptance. PNG DPI is PNG metadata only. Quick PNG, Copy plot and
CSV/TSV remain separate actions. Owned errors use bilingual code/parameter
messages; original provider text and filenames remain inspectable.
