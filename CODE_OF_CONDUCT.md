# Code of Conduct

MSCanvas follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Project maintainers are expected to provide a welcoming, harassment-free environment for contributors regardless of background, identity, experience or institutional affiliation.

Until a dedicated project contact is published, conduct reports should be sent privately to the repository owner through GitHub. Reports will be reviewed promptly and handled with discretion.
